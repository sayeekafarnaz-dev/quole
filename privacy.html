Quole — development privacy information

This development notice must be reviewed against Qlogue’s privacy notice before public use.

When you consent and send a message, your message and up to 14 previous conversation messages are processed by the shared Quole backend and Anthropic’s API to generate an answer. Only approved public-facing product knowledge is included. Do not send confidential, personal or sensitive information.

Conversation text is held in browser session storage, separated by website context, and cleared after 30 minutes of inactivity when the widget is running or next loaded. You can clear it at any time. The application has no conversation database, conversation logging or analytics integration. Requests exist transiently in server memory during processing. Hosting request-body logging must remain disabled.

Production uses Cloudflare Turnstile for abuse protection, which processes browser/network information and verification tokens. The backend keeps temporary per-IP counters for up to one minute and an aggregate daily request count without conversation contents.

External provider retention, data region and contractual processing terms have not been confirmed. Public use is blocked until the approved privacy notice covers Anthropic, Cloudflare and the hosting provider, and provider retention settings are confirmed. This application cannot enforce deletion in an external provider’s systems.

Questions: enquiries@qlogue.com.
